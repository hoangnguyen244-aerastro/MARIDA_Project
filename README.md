PIPELINE STEPS

1. Filter data (Normal: water only, Anomaly: ship/debris)
2. Extract 18 wavelet features (energy, entropy, skewness)
3. Train SVM with grid search (C, gamma)
4. Evaluate (accuracy, precision, recall, F1, AUC)
5. Compare wavelet families (db4, sym4, bior3.5, coif2, haar)

METHODOLOGY NOTE (v5 - leakage-free evaluation)

The corrected evaluation branch uses the official MARIDA train/validation/test
split files distributed with the dataset. Train + validation samples form the
development set for 5-fold cross-validation and hyperparameter selection.
The official test split is never used for model selection and is evaluated once.

Feature z-score parameters are fitted on development data only. Step 2 stores
unnormalized transformed wavelet features and preserves sample identities.
Step 5 uses the same C/KernelScale grid and CV-only selection for every wavelet.
Step 6 benchmarks held-out test images and applies the same log transform used
during training.

IMPORTANT: Results generated by the previous v4 random 70/30 pipeline are not
directly comparable to v5 results. Re-run run_all.m before updating manuscript
tables, figures, or performance claims.
